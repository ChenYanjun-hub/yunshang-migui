## 二、关键设计决策

### 视觉语言巩固
- **kicker → h1 → en italic 副标 → cn 描述** 的 header 模式作为全站标准，所有页面统一。
- **EB Garamond italic** 承担一切英文小字，与 Noto Serif SC 形成视觉对仗，把"博物馆/档案馆"气质拉满。
- **hairline 网格 + gap-px + bg-border-subtle** 取代实线分割，构建"建筑感"。
- **图源**：Picsum 灰阶 + CSS sepia 0.18 + contrast 0.96，模拟老照片质感，竞赛 demo 阶段无需自备素材。

### 火车车厢卡片（伪 3D）
- 顶部金色细带（车顶）→ 车厢编号 No.0X → 中文图标 → 标题 + 英文 + 描述 → 底部车窗格（3 个方块）+ Enter 箭头
- Hover：`translateY(-10px) + rotateX(6deg)` + 多层阴影 + accent 描边淡入
- 行下方两条铁轨：实线 + 虚线渐变
- `perspective: 1400px` 在父容器，`transform-style: preserve-3d` 在卡片

### Navigation 升级
- 双语菜单（中文 + EN italic 小字两行）
- `usePathname()` 标记当前路由（accent 色 + 满宽下划线）
- 滚动触发 backdrop-blur + 底部 hairline，未滚动时只有顶部渐变遮罩
- 右侧加 `/user` 入口（"旅" 字方形图标）

## 四、技术备忘

### 已验证
- Next 16 的 `usePathname` 与 `useRouter` 仍从 `'next/navigation'` 导入，API 无变化
- Tailwind v4 `@theme inline` 配合 CSS 变量切换主题完美支持，所有组件 className 不变
- Picsum (`https://picsum.photos/seed/{seed}/{w}/{h}?grayscale`) 在 plain `<img>` 下无需 next.config 配置
- `<img>` 加 `width` + `height` + `loading="lazy"` + `decoding="async"` 三件套防 CLS

### 待验证 / 风险
- Picsum 在生产环境的可用性和速度；正式上线前替换为本地素材或 CDN
- 火车车厢卡片在窄屏 mobile 上的 rotateX 视觉效果
