## 五、技术决策

### 图片上传走客户端直传
- 优点：不经过 Next 服务端，速度快、不占 Edge 函数时长
- 安全：Storage RLS 控制谁能写入；publishable key 只允许 admin 角色操作 `public-assets`
- 风险：理论上 admin 用户可绕过 UI 大量写入，但仅团队内部使用，可接受

### Server Actions 统一用 useActionState
- React 19 + Next 16 的现代姿势
- 通过 `bind(null, id)` 把动态 id 注入 update action

### 状态机改"任意切换"
- 实战需求：已发布 → 改一改 → 重新发布
- 严格状态机太死，且演示场景没有审计要求
