## 四、踩坑与笔记

1. **AI SDK v6 的 `convertToModelMessages` 是 async**，v5 是同步的。漏 `await` 时类型错误是 `Promise<ModelMessage[]>` not assignable to `ModelMessage[]`。
2. **v6 `useChat` 不再内置 `input` 状态**——必须自己 `useState` + `sendMessage({ text })`。`handleInputChange` / `handleSubmit` 已移除。
3. **`DefaultChatTransport`** 必须从 `ai` 导入，不是 `@ai-sdk/react`。
4. **`createOpenAICompatible`** 用 `.chatModel('deepseek-chat')` 而不是 `('deepseek-chat')` 直调（后者是旧 v4 用法）。
5. **京華老宋体 CDN 体积过大**——若答辩前一定要上，建议自部署 woff2 子集化（只取常用 6500 汉字 + 标点，可压到 2-3MB）。

### 7.2 Galaxy（已淘汰）
- 路径：`src/components/animations/Galaxy.tsx`（保留文件不删，备用）
- 依赖：`ogl@^1.0.11`
- 第一次试：暖色调（hueShift=18, saturation=0.55）→ 用户反馈"像空气中的霉菌"，与米色档案纸冲突
- 第二次试：灰度去饱和 + multiply 混合 + 顶部 55% 高度限制 → 仍未采用
- 教训：高对比度的"星点"在米色档案纸上无论如何都会读出生物/孢子感，**色相饱和度不是关键，"点状离散"形态本身就不搭"档案"调性**

### 7.3 Threads（保留并采用）
- 路径：`src/components/animations/Threads.tsx`
- 依赖：`ogl@^1.0.11`（已被 Galaxy 引入，不增加 bundle）
- 参数：`color=[0.545, 0.180, 0.121]`（朱砂 RGB）+ amplitude 0.9 + distance 0.35 + 椭圆 multiply 遮罩 + opacity 0.55
- 视觉效果：朱砂丝线在中央缓慢飘动，向四周淡出 —— 像墨与朱砂在档案纸中央晕开
- 选它的理由：**线性形态**比"星点"更接近"墨迹/纤维"的纸张语义；色彩绑定品牌色（朱砂红）一举两得

### 7.4 React Bits 接入工作流（备忘）
- 拉取方式：`curl https://reactbits.dev/r/<Name>-TS-TW.json` → `python3` 解 JSON 写文件 → 装 `dependencies` 字段里的 npm 包
- 命名约定：`<Name>-TS-TW`（TypeScript + Tailwind v4 变体）；不存在的名字站点会返 200 + 主页 HTML（伪 200，要看 body 是 JSON 才算命中）
- 命中失败：Squares 试了 7 个变体名都返主页 HTML，疑似该组件未在 registry 暴露独立路径
- 适配项目：默认配色多为深色主题，咱米色档案纸需要：(1) 灰度/朱砂调色 (2) opacity ≤ 0.55 (3) `mix-blend-mode: multiply` (4) 渐变遮罩限制覆盖区域
