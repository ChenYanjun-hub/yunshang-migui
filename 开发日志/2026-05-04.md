## 一、本日主线
前端 UI/交互优化第一日。对标 oculi-mundi.com 的博物馆质感，确立全站主基调；落地双主题 token 系统；新增独立"引导页"路由 `/` + 时光隧道转场动效。

## 二、关键决策

### 风格路线（C → B）
- 最初约定 C 路线：首页深空沉浸，内页博物馆白底
- 实跑后觉得深色违和，**改为全站统一博物馆白底**（B 路线）
- 深空主题作为可选项保留：`[data-theme="immersive"]`

### 配色锁定
- 背景米色 `#f8f5ee`，主文 `#1a1814`
- 强调色「米轨复古金」白底版 `#a8884a`，深色版 `#c9a961`
- 用户后续会提供云南米轨的官方主题黄，再统一替换

### 引导页架构
- `/` → 独立引导页（点击任意位置进入）
- `/home` → 原首页内容（PRD 中 `/home` 即沉浸式时空首页）
- Navigation 的 logo 链接指向 `/home` 而非 `/`，避免点 logo 又被引导页拦截

### 入场动效
- 时光隧道：背景缩放 1× → 2.6× + 模糊 0 → 10px + 暖光环径向扩散 + 文字淡出后退
- 总时长 850ms，进入主页后 `page-fade-in` 540ms 淡入
- 暂不做 sessionStorage 记忆，每次访问 `/` 都展示引导页

## 四、技术备忘

- Next.js 16.2.4 + React 19 + Tailwind v4。AGENTS.md 强调"This is NOT the Next.js you know"，写代码前查 `node_modules/next/dist/docs/`，不能凭记忆
- 项目尚未安装动画库（Framer Motion）和 3D 库（Three.js）。当前所有动画用纯 CSS + React state 实现，能扛住竞赛 MVP
- Tailwind v4 的 `@theme inline` + CSS 变量方式是双主题切换的关键，组件代码不需要改任何 className
- 引导页修过的隐性 bug：`setTimeout` 必须用 `useRef` 管理 + 卸载时清理 + `pageshow` 事件处理 bfcache 恢复，否则浏览器后退会跳过引导页
