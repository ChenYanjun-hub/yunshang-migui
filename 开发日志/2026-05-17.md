## 踩坑与笔记

### 1. cn-font-split 在 Node 24 + macOS 挂了（字体子集化方案 B → B'）
- 第一次试 `npx cn-font-split` 报错 `Invalid type name '5e78c6e7-2a0d-...'`（koffi/ffi 兼容问题，UUID 当 type 名传入）
- 切换到 Python fonttools (`pyftsubset`) — 装到 `~/Library/Python/3.9/bin/`，PATH 没有，脚本里写死路径
- 教训：跨语言/原生绑定的 CLI 工具在新 Node LTS 上经常挂；优先选纯 Python / 纯 Rust / 纯 Go 的工具链，少坑

### 2. ZeoSeven CDN 切片虽好，但演示场景 0 风险更重要（A vs B 决策）
- ZeoSeven 用 cn-font-split 切了 503 个 woff2 unicode-range 片，按需加载体积极小
- 但演示日现场网络不可控，外网 CDN 是单点失败 → 选 B（本地子集 999 字符）
- 决策原则：**演示前一周内的字体方案 = 选 0 网络依赖 + 单文件**，而不是"技术最优"
- 副效应：将来如果文案大改，重跑 `scripts/build-kinghwa-subset.sh` 即可（扫静态文本 → 重新子集）

### 3. CSS L89 早就预留了 "Kinghwa OldSong"，但 family 名拼错 + 没 @font-face
- 5/09 写设计系统时把名字写成 `"Kinghwa OldSong"`（中间有空格），但字体实际 family name 是 `"KingHwaOldSong"`（无空格）
- 加上一直没 @font-face 声明，浏览器一直 fallback 到 Noto Serif SC，肉眼难分辨
- 这个 bug 潜伏了 8 天没被发现 — 提醒：**写设计系统的"字体变量"时，没接入的 family 必须写注释**，不然会形成"看起来在用 / 实际没用"的假象

### 4. ErrorBanner auto-clear 没办法在 Preview 里"看到瞬间清空"
- 我想验证 "错误存在 → submit 新问题 → 错误条立即消失 → 然后新请求被拦再次出现"
- 实际上 `clearError + sendMessage` 是同步连续调用，React 一帧内 commit，截图抓不到清空瞬间
- 折中：验证 failCount 从 3→4（说明 submit 成功），+ alertText 在两帧间发生过变化（用户气泡列表新增"先卸拦截测试 auto-clear"作为旁证）
- 这种交互验证的"原子性"问题，未来如果上 E2E（Playwright），可以用 `expect(banner).not.toBeVisible()` 配 `polling: 50ms` 抓中间态

### 5. admin/community 路由有 auth 守卫，Preview 验不了 — 改用 trust 代码路径
- Preview 没登录 → 跳 /auth/login → 验证终止
- 代码本身很简单（select + reduce + 渲染卡片 + 列表 + 静态说明块），类型 OK
- 教训：**admin 路由的验证不能纯靠浏览器自动化**，得有 dev-time 的 mock-auth 或种子账号 cookie；当前演示前不投入此基建

### 6. Claude Preview vs Claude in Chrome
- 今天 Chrome extension 没连上，第一时间切到 Claude Preview（自带浏览器）
- Preview 用的是手机视图（约 768 px），效果跟真实演示设备（桌面 1440+）不一致 —— 但骨架/交互验证都覆盖
- 真实演示前 1-2 天，得换桌面浏览器再拉一遍每个页面（避免响应式断点 bug）

### 7. cards 不是 button，是 div+onClick（Archive Lightbox 触发 path）
- 想用 `preview_click` 一键打开 Lightbox，但 archive card 是普通 div 带 onClick，CSS 选择器写不出
- 走 `preview_eval` 用 `document.querySelector('img[alt="..."]').closest('[class]').click()` 兜底
- 提醒：**未来如果想给 Lightbox 加可访问性**（键盘 Enter 触发 / aria-label / role），现在的 div+onClick 模式得改成 button
