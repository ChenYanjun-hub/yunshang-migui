## 一、项目启动

### 1.1 需求理解

阅读项目文档，理解核心定位：

- **产品定位**：工业遗产数字化保护 + 文旅智能导览 + 研学社区平台
- **Slogan**：一条云上米轨，半部西南近代史
- **目标用户**：Z世代青年、文旅游客、研学师生、文史研究者、摄影爱好者
- **视觉风格**：对标 Oculi Mundi 的深色极简沉浸风格，融合美术学院派高级感与建筑设计结构逻辑

### 1.2 技术选型

根据敏捷开发文档确定技术栈：

| 层级 | 技术 |
|------|------|
| 框架 | Next.js 16 (App Router) |
| UI 库 | React 19 |
| 样式 | Tailwind CSS v4 |
| 字体 | Noto Serif SC + Noto Sans SC + EB Garamond |
| 地图 | Mapbox / 高德地图 (待集成) |
| 后端 | Supabase (待集成) |

## 二、项目初始化

### 2.1 创建项目

```bash
npx create-next-app@latest yunshang-migui \
  --typescript --tailwind --eslint --app \
  --src-dir --import-alias "@/*" --use-npm
```

### 2.2 遇到的问题

**问题**：项目路径包含中文字符（`滇越铁路垂直领域数字化知识服务平台`），Turbopack 编译时报错：
```
start byte index 7 is not a char boundary; it is inside '铁' (bytes 6..9)
```

**解决方案**：修改 `package.json`，使用 Webpack 构建：
```json
"build": "next build --webpack"
```

## 三、设计系统构建

### 3.1 色彩系统

定义了两套主题，支持切换：

#### 博物馆风格（默认·浅色）
```css
--background: #f8f5ee;     /* 米白底色 */
--foreground: #1a1814;     /* 深褐文字 */
--accent-gold: #a8884a;    /* 复古米轨金 */
--surface-1: #ffffff;
--border-hard: rgba(26, 24, 20, 0.18);
```

#### 沉浸式风格（深色）
```css
--background: #0a0a0b;     /* 深空黑 */
--foreground: #ede8dd;     /* 暖白文字 */
--accent-gold: #c9a961;    /* 复古米轨金 */
--surface-1: #15161a;
--border-hard: #3a3a3a;
```

### 3.2 字体系统

| 用途 | 字体 | 特点 |
|------|------|------|
| 中文标题 | Noto Serif SC | 衬线体，学术感 |
| 中文正文 | Noto Sans SC | 无衬线，易读 |
| 英文标题 | EB Garamond | 经典衬线，优雅 |
| 代码/数据 | JetBrains Mono | 等宽字体 |

### 3.3 组件风格

- **建筑感边框**：1px solid 硬边框，无圆角
- **卡片悬停**：上浮 8px + 边框变金色
- **分割线**：渐变式，两端透明
- **过渡动画**：280ms ease (主题切换) / 540ms ease-out (页面淡入)

## 四、数据模型设计

创建 `src/types/index.ts`，定义核心接口：

### 4.1 用户体系
- `UserRole`：用户角色枚举 (guest/user/vip/creator/business/admin)
- `User`：用户基础信息
- `VIPMembership`：会员状态

### 4.2 史料档案
- `ArchivePeriod`：时期分类 (修建期/运营期/民国/建国后/遗产保护)
- `ArchiveType`：史料类型 (照片/文献/地图/图纸/报刊/口述史)
- `ArchiveItem`：史料档案项

### 4.3 站点与地图
- `StationCategory`：站点分类 (车站/桥梁/隧道/水塔/机修厂/建筑/纪念设施/景点)
- `StationPoint`：站点信息
- `HeritagePoint`：遗存点位
- `VRHotspot`：VR全景热点

### 4.4 社区与电商
- `UGCContent`：用户创作内容
- `Product`：商品信息
- `Order`：订单信息
- `CheckInRecord`：打卡记录
- `DigitalStamp`：电子印章

## 五、路由架构

### 5.1 路由规划

实现 8 大一级路由模块：

| 路由 | 模块名称 | 核心功能 |
|------|---------|---------|
| `/` | Intro 入口 | 隧道过渡动画入口页 |
| `/home` | 沉浸式主页 | 导航卡片 + 数据统计 + 时间轴 |
| `/archive` | 数字史料藏馆 | 瀑布流 + 筛选 + Lightbox |
| `/exhibition` | 米轨光影展 | 3D照片墙 + UGC创作 |
| `/cloud-tour` | 云游导览 | GIS地图 + VR全景入口 |
| `/offline-tour` | 线下导览 | GPS轨迹 + AR识别 + 游戏化打卡 |
| `/community` | 研学社区 | AI答疑 + 论坛 + 学堂 |
| `/store` | 文创商城 | 商品列表 + 购物车 |
| `/user` | 个人中心 | 会员体系 + 资产管理 |

### 5.2 Intro 入口页设计

**交互逻辑**：
1. 全屏展示欢迎文案（中英双语）
2. 点击任意处 / 按 Enter / 空格 → 触发隧道过渡
3. 850ms 动画：背景缩放 2.6x + 模糊 10px + 淡出
4. 自动跳转至 `/home`

**视觉效果**：
- 背景图 + grayscale(0.55) + sepia(0.18) 复古滤镜
- 金色径向渐变光晕
- 底部 "Click anywhere to enter" 脉冲提示
